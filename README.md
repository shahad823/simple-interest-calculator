# Simple Interest Calculator

A Bash command-line calculator that computes simple interest from user input.

## Inputs
- Principal: the initial amount of money.
- Rate: the annual interest rate as a percentage.
- Time: the time period in years.

## Formula
Simple interest = principal * rate * time / 100

## Usage
Run `bash simple-interest.sh` and enter the principal, rate, and time when prompted.

Example: principal 1000, rate 5, and time 2 produce simple interest of 100.00.
