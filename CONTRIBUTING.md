# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute
1. Open an issue describing your bug or proposed improvement. Include steps to reproduce bugs and expected behavior.
2. Fork this repository and create a branch for your change.
3. Make focused changes and verify that the calculator works.
4. Commit your changes and open a pull request describing what changed and how you tested it.

Please follow CODE_OF_CONDUCT.md in all project interactions.
